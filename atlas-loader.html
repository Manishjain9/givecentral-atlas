Atlas · Design system

Screen loader

One general loader for the whole platform. Call atlasLoader.show() anywhere and the status auto-rotates neutral reassurance lines. Pass your own text to override it, and it handles long waits and a success beat for you.

Live preview · default rotating status
Loading

The preview loops the rotating lines. The buttons drive the real full-screen overlay. Long-wait note is set to appear after 1.6s here for the demo (defaults to ~7s, then escalates at ~14s).

Use it anywhere
Default

atlasLoader.show() — rotates "Loading → Getting things ready → Fetching your data → Almost there" until you hide it. No config.

Override

atlasLoader.show('Posting batch…') shows your exact text. Update live with setStatus('…').

Finish

atlasLoader.success('Saved') shows a green ✓ for a beat, then fades out. Or just hide().

Long waits

Automatic — a soft note fades in after slowAfter (default 7s) and escalates if it keeps going.

  var slowT1,slowT2,rotTimer,steps=[],cur=0;
  function E(id){return document.getElementById(id);}
  function txt(){return el.querySelector('#al-status .al-txt');}
  function reveal(){el.classList.remove('leaving');el.classList.add('show');}

// Default — rotates reassurance lines, works on any screen:
atlasLoader.show();
atlasLoader.hide();

// Override with specific text when a screen has it:
atlasLoader.show('Posting batch BX-2026-014 · 22 gifts');
atlasLoader.setStatus('Queuing receipts');   // update live
atlasLoader.success('Batch posted');         // green ✓ beat, then fades

// Long-wait note is automatic; tune the first threshold:
atlasLoader.show(null, { slowAfter: 5000 });

API: show(message?, {slowAfter}) · setStatus(message) · success(message?) · hide() · optional checklist(steps, {auto, hideWhenDone}) + completeStep(). With no message, show() auto-rotates the general reassurance lines.
