Multi-Factor Authentication

Require all users you manage to confirm their identity with a one-time code at login. Turn on the channels users can receive codes on — enable one or both. Codes are sent to the mobile number or email address already on each user's profile.

Text message (SMS) Enabled

Code sent to the user's mobile number on file.

Email Disabled

Code sent to the user's email address on file.

Default method shown first at login
Make sure every user has a mobile number or email address on file for the method(s) you enable. If a user is missing the required contact detail, they won't receive verification codes and won't be able to log in — add it in the Manage User screen.
