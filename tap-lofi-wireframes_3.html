GiveCentral TAP — Ticket Events

Low-fidelity wireframes. Layout, hierarchy, and flow only — no color, type, or final copy. Grayscale on purpose so the conversation stays on structure. Each frame is a phone screen; numbered blue callouts under it describe behavior and interaction.

Assumptions: reader-operated is the primary path (both branches drawn) · multi-ticket-type selector shown (single-price = collapsed version) · no held-inventory timers at this fidelity.

placeholder / container text block (real labels used where they aid reading) primary action interaction note
